# IBAM Projection Figure Renderer

Standalone rendering pipeline for generating evolutionary projection figures for the manuscript:

*C12orf29 encodes IBAM (In Between Actin and Myosin), a sarcomeric protein with a conserved actomyosin interaction grammar spanning approximately one billion years of evolution.*
(Manuscript in preparation)


This repository provides a lightweight reproducibility package for visualising conserved interaction patterns recovered by the IBAM evolutionary projection workflow. The script renders projection-style figures from aligned sequence and contact-space inputs, allowing conserved biochemical features to be visualised across broad phylogenetic distance.

The purpose of this repository is both practical and conceptual:

- to provide transparent reproducibility for projection-based manuscript figures
- to demonstrate how conserved interaction features emerge from multi-taxon contact-space analysis
- to visualise the biochemical coherence underlying the proposed IBAM–MyhT interaction grammar

The current dataset spans 26 taxa distributed across major evolutionary lineages including bacteria, Discoba, cnidarians, lophotrochozoans, ecdysozoans, tunicates, and vertebrates.

---
## Conceptual overview

The projection figures generated by this workflow are designed to visualise conserved interaction-space organisation rather than conventional sequence conservation alone.

The underlying IBAM workflow integrates:

-  molecular dynamics contact persistence
-  evolutionary projection into shared contact space
-  dual-constraint filtering based on phylogenetic occupancy and biochemical coherence
-  visualisation of conserved interaction grammar across divergent taxa

Rather than searching for rigid sequence motifs, the approach aims to recover conserved biochemical roles maintained across deeply divergent evolutionary contexts.
